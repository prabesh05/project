# Hungry Hoppers Project

This repository contains two applications:

## 1. Hungry Hoppers Food Ordering Website (HTML/CSS/JS)

The original food ordering website with a modern interface for ordering food online.

- Located in the root directory
- Files: `index.html`, `index.css`, `pages/`
- Simple HTML/CSS/JavaScript website

## 2. Student Management System (Laravel)

A comprehensive Laravel-based student management system.

- Located in the `student-management/` directory
- Full-featured CRUD application
- Built with Laravel 11, PHP 8.3, SQLite database

### Quick Start for Student Management System

```bash
cd student-management
composer install
php artisan serve
```

Then visit http://localhost:8000

### Features

- **Student Management**: Add, edit, view, and delete students
- **Course Management**: Manage courses with codes, credits, and descriptions
- **Enrollment Management**: Track student enrollments in courses with grades
- **Modern UI**: Clean, responsive interface
- **Sample Data**: Pre-populated with example data for testing

For detailed documentation, see [student-management/README_STUDENT_MANAGEMENT.md](student-management/README_STUDENT_MANAGEMENT.md)
